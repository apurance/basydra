# MVP 验收记录

日期：2026-10-06。测试目标：本机 Windows 客户端 + `ssh ai` 上的 Linux amd64 探针。

## 构建与单元测试

- 测试使用 Go 1.27.1。
- `scripts/build.ps1`：Windows 原生 `go test ./...` 与 `go vet ./...` 通过。
- Windows amd64、Linux amd64、Linux arm64 构建通过。arm64 只验证交叉编译，未在 arm64 设备运行。
- Linux 探针测试交叉编译后上传 `ai` 执行，全部通过：CPU guest 计数、内存 available 解析、容器网络去重、历史重启/不完整追加恢复、过期日志清理、Token/过期快照、历史参数约束。
- Windows 客户端测试通过：节点传输和 SSH 参数验证、配置持久化、Token 不返回、离线状态、保存失败不改变运行状态、跨来源/Host 限制。
- 前端 JavaScript 语法检查、PowerShell 脚本语法检查通过。未执行 Go race detector。

## 实际部署

- `basydra-agent.service` 为独立 systemd 服务，开机启用，使用 DynamicUser、LoadCredential、StateDirectory。
- 实际监听仅为远端 `127.0.0.1:19790`。
- 本机客户端在 `127.0.0.1:17890`，通过由客户端启动的 OpenSSH 隧道读取探针。
- 部署二进制 SHA-256 与本机构建一致：`b0c704f190eb82bafb8ec0132b8a182d6f012e983759c168004d9ae7df6df245`。
- 实际快照包含 CPU、内存、Swap、根目录磁盘、网络、负载、运行时间与 4 个 CPU 核心；无 Token 请求返回 HTTP 401。
- 停止探针后，客户端自动变为离线，并保留最后一个快照。
- 重新启动探针后，客户端自动恢复在线；历史的首个时间戳保留，测试中的采样点从 42 增至 43。
- 主动关闭客户端自己的 SSH 进程后，客户端建立新隧道并恢复读取。

## 界面验收

使用 Edge 在真实节点上验证：资源卡片、实时节点行、历史曲线、15 分钟范围切换、搜索无匹配状态、添加表单、离线详情提示、移除确认框与取消操作。通过表单创建临时节点后，经客户端 API 删除临时配置；真实 `ai` 节点保留。

完整截图保存在 `.local/dashboard.png`。移动端 390px 布局检查包含表格横向滚动、详情布局与曲线；未出现页面整体横向溢出。浏览器控制台没有 warning/error。

## 实际覆盖范围

24 小时保留是已配置的默认值，过期清理通过模拟日志测试；本轮真实探针只运行数分钟，并未等待完整 24 小时。HTTPS 证书验证路径使用 Go 系统 CA，尚未在真实公网 HTTPS 节点验收。本轮未测试 Netdata/PCP、告警或多用户功能，这些功能不在当前 MVP 内。
